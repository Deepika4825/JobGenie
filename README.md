# JobGenie

**An AI-powered career assistant that analyzes resumes and provides smart, real-time job recommendations.**
Get ATS scores, relevant job matches, and personalized improvement suggestions.


## Live Demo

 https://job-genie-tan.vercel.app


## Features

* Resume upload (PDF)
* AI-based resume analysis using LLM
* ATS score generation
* Real-time job recommendations with apply links
* Skill gap identification
* Personalized suggestions


## Highlights

* Uses LLM for intelligent resume understanding
* Fetches real-time job data using APIs
* Provides direct apply links for job roles
* Clean and responsive UI built with React
* Used uptime monitoring to keep the backend active and responsive.
* Ensured consistent API availability during usage and testing.



## Tech Stack

Frontend: React.js, Tailwind CSS
Backend: Flask (Python)
AI: LLM (Gemini/OpenAI)
API: Job Search API
Database: SQLite / MongoDB



## Future Improvements

* Advanced job filtering (location, salary)
* Save or bookmark jobs
* Email alerts for new job postings
